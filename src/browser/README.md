# 浏览器客户端代码

这是 Code Server 的浏览器客户端代码，提供了 Web 界面的 HTML、CSS 和 JavaScript 文件。

## 目录结构

```
browser/
├── pages/          # 页面模板和样式
├── media/          # 静态资源文件
├── robots.txt      # 搜索引擎爬虫配置
├── security.txt    # 安全策略文件
└── serviceWorker.ts # 服务工作者脚本
```

## 核心组件

### 页面模板 (pages/)

#### 登录页面 (login.html/css)
- 用户认证界面
- 响应式设计
- 表单验证
- 错误提示

#### 错误页面 (error.html/css)
- 错误信息展示
- 用户友好的错误提示
- 返回和重试选项

#### 全局样式 (global.css)
- 通用样式定义
- 主题支持
- 响应式布局
- 字体和图标

### 静态资源 (media/)

#### 图标文件
- `favicon.ico` - 网站图标
- `favicon.svg` - SVG 格式图标
- `favicon-dark-support.svg` - 深色主题支持

#### PWA 图标
- `pwa-icon-192.png` - 192x192 PWA 图标
- `pwa-icon-512.png` - 512x512 PWA 图标
- `pwa-icon-maskable-192.png` - 可遮罩图标
- `pwa-icon-maskable-512.png` - 可遮罩图标

#### 其他资源
- `templates.png` - 模板预览图

### 服务工作者 (serviceWorker.ts)
- PWA 功能支持
- 离线缓存
- 推送通知
- 后台同步

### 配置文件

#### robots.txt
- 搜索引擎爬虫控制
- SEO 优化配置

#### security.txt
- 安全策略声明
- 漏洞报告联系方式
