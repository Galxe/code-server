# 国际化支持 (i18n)

这是 Code Server 的国际化支持目录，提供了多语言界面和本地化功能。

## 目录结构

```
i18n/
├── index.ts       # 国际化核心逻辑
└── locales/       # 语言包文件
    ├── en.json    # 英语 (默认)
    ├── zh-cn.json # 简体中文
    ├── ja.json    # 日语
    ├── th.json    # 泰语
    └── ur.json    # 乌尔都语
```

## 核心功能

### 语言包管理 (index.ts)
- 动态语言包加载
- 自定义字符串支持
- 语言检测和切换
- 回退语言处理

### 支持的语言

#### 英语 (en.json)
- 默认语言
- 完整的界面文本
- 开发基准语言

#### 简体中文 (zh-cn.json)
- 中文用户界面
- 本地化术语
- 文化适应性调整

#### 日语 (ja.json)
- 日语用户界面
- 敬语和礼貌表达
- 日式排版支持

#### 泰语 (th.json)
- 泰语用户界面
- 泰语字体支持
- 本地化表达

#### 乌尔都语 (ur.json)
- 乌尔都语用户界面
- 从右到左 (RTL) 支持
- 阿拉伯语系字体

## 技术实现

### 语言包格式
```json
{
  "I18N_LOGIN_TITLE": "登录",
  "I18N_PASSWORD_PLACEHOLDER": "请输入密码",
  "I18N_SUBMIT": "提交"
}
```

### 动态加载
- 支持运行时语言切换
- 自定义语言包覆盖
- 配置驱动的语言选择

### 回退机制
- 缺失翻译的回退处理
- 默认语言兜底
- 优雅降级支持

## 使用方法

### 配置语言
```bash
# 通过命令行参数
code-server --locale zh-cn

# 通过环境变量
export LOCALE=zh-cn
code-server
```

### 自定义字符串
```bash
# 指定自定义语言包文件
code-server --i18n /path/to/custom-strings.json
```

### 语言包结构
```json
{
  "locale": "zh-cn",
  "strings": {
    "I18N_CUSTOM_MESSAGE": "自定义消息"
  }
}
```

## 开发指南

### 添加新语言
1. 在 `locales/` 目录下创建新的语言包文件
2. 翻译所有必需的字符串键
3. 在 `index.ts` 中注册新语言
4. 测试语言包完整性

### 字符串键规范
- 使用 `I18N_` 前缀
- 描述性的键名
- 保持键名的一致性
- 支持参数插值

### 测试验证
- 语言包语法检查
- 翻译完整性验证
- 界面布局测试
- 文化适应性检查
